# 🃏 德州扑克小程序 — 从新手到高手

一款功能完整的命令行德州扑克游戏，专为新手设计，配备详细的中文教学系统，帮助玩家从零开始快速提升扑克技能。

---

## 🚀 如何运行这个程序？

### 前置条件

只需要安装 **Python 3.10 或更高版本**，无需任何第三方库。

> 检查你的 Python 版本：
> ```bash
> python --version
> # 或
> python3 --version
> ```

### 方法一：使用根目录启动脚本（推荐）

```bash
# 在项目根目录下运行：
python run.py
```

### 方法二：直接运行主程序

```bash
# 从项目根目录：
python texas_holdem/main.py

# 或进入子目录后运行：
cd texas_holdem
python main.py
```

运行后会出现主菜单，按提示输入数字选择对应功能即可。

## 🎮 程序功能

启动后会显示主菜单：

```
══════════════════════════════════════════════════
  🎮 主菜单
══════════════════════════════════════════════════
  [1] 开始游戏
  [2] 学习教程
  [3] 快速测验
  [4] 查看牌型速查表
  [0] 退出
══════════════════════════════════════════════════
```

| 选项 | 功能说明 |
|------|---------|
| **1 开始游戏** | 配置对手数量、AI难度、筹码数量、盲注后开始对战 |
| **2 学习教程** | 8章互动教程（规则/牌型/位置/赔率/起手牌/诈唬等） |
| **3 快速测验** | 5题知识测验，检验你的学习成果 |
| **4 牌型速查** | 随时查看10种牌型大全 |

### 教学模式（新手必开）

开始游戏时选择开启教学模式，每次轮到你下注时会实时显示：

- 📊 **当前最佳牌型**及说明
- 🎯 **胜率估算**（蒙特卡洛模拟）
- 💡 **听牌提示**（Outs）：还有多少张牌能改善你的手牌
- 📐 **底池赔率分析**：数学上是否值得跟注
- ⭐ **起手牌评级**：翻牌前评估底牌质量

### AI 难度选择

| 难度 | 说明 | 适合人群 |
|------|------|---------|
| 新手 AI（默认）| 随机出牌，偶尔犯错 | 完全新手 |
| 中级 AI | 基于牌力和底池赔率决策 | 了解基本规则后 |
| 高手 AI | 综合胜率、赔率、诈唬策略 | 有一定经验后 |

## 🃏 德州扑克基本规则

每位玩家获得 2 张私有底牌，加上 5 张公共牌，组成最强的 5 张牌型。

| 游戏阶段 | 说明 |
|---------|------|
| 翻牌前（Pre-Flop）| 发2张底牌，第一轮下注 |
| 翻牌（Flop）| 翻出3张公共牌，下注 |
| 转牌（Turn）| 翻出第4张公共牌，下注 |
| 河牌（River）| 翻出第5张公共牌，最终下注 |
| 摊牌（Showdown）| 比较牌型，最强者赢得底池 |

### 牌型大全（从强到弱）

| 牌型 | 示例 |
|------|------|
| 🥇 皇家同花顺 | A♠ K♠ Q♠ J♠ 10♠ |
| 同花顺 | 9♥ 8♥ 7♥ 6♥ 5♥ |
| 四条（炸弹）| K♠ K♥ K♦ K♣ 2♠ |
| 葫芦 | A♠ A♥ A♦ K♣ K♠ |
| 同花 | A♣ J♣ 9♣ 5♣ 2♣ |
| 顺子 | 8♠ 7♥ 6♦ 5♣ 4♠ |
| 三条 | J♠ J♥ J♦ 8♣ 3♠ |
| 两对 | A♠ A♥ K♦ K♣ 7♠ |
| 一对 | Q♠ Q♥ 9♦ 6♣ 2♠ |
| 高牌 | A♠ J♥ 8♦ 5♣ 2♠ |

## 📈 新手进阶学习路线

1. **第一步（完全新手）**
   - 选 `[2] 学习教程` 快速了解规则和牌型
   - 开启教学模式，对战新手 AI，熟悉操作流程

2. **第二步（入门）**
   - 完成 `[3] 快速测验`，检验理解是否到位
   - 继续对战中级 AI，尝试理解赔率提示

3. **第三步（进阶）**
   - 关闭教学模式，自己判断赔率
   - 挑战高手 AI，注意对手的下注模式

4. **第四步（高手）**
   - 学习诈唬时机和位置策略
   - 同时对战多名高手 AI
