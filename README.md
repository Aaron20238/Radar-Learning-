## ⚖️ 智能合同审阅助手

### 功能介绍

扮演拥有 20 年经验的资深商事律师，帮助你：

- 📂 **文档解析**：支持上传 `.docx`（Word）、`.pdf` 和 `.txt` 文件，或直接粘贴合同文本
- 🔍 **风险扫描**：自动识别高风险 🔴、中风险 🟠、低风险 🟡 条款
- 📝 **两种修订模式**：
  - **模式 A（对比修订）**：保留原文，用 `~~删除线~~` 标注原内容，`**高亮**` 显示新内容
  - **模式 B（直接替换）**：直接输出修改后的完整条款
- ⚖️ **法律依据**：每条修改建议均引用《民法典》等相关法律条文
- 💬 **谈判建议**：解释修改背后的法律逻辑，辅助合同谈判

### 快速开始

```bash
# 安装可选依赖（Word/PDF 解析）：
pip install python-docx pypdf

# 启动合同审阅助手：
python -m contract_review
```

```
  [1] 🔴 高风险 — 违约金比例过高（第三条）
  [2] 🔴 高风险 — 无限连带责任/无上限赔偿（第三条）
  [3] 🔴 高风险 — 知识产权归属不利（第四条）

### 🔴 风险点：违约金比例过高 (第三条)

**问题分析**：合同约定的违约金比例超过 30%，...

**原文与修订对比**：

~~违约金应为合同总金额的 50%，且乙方需承担由此产生的一切连带责任。~~
**违约金应为合同总金额的 20%，或以守约方实际遭受的直接损失为限...** （此处为高亮修改）

**💡 律师解读**：
- **法律依据**：《中华人民共和国民法典》第五百八十五条
- **谈判建议**：可建议将违约金上限调整至 20%–30% 区间...
```

### 识别的风险类型

| 风险级别 | 风险类型 |
|---------|---------|
| 🔴 高风险 | 违约金比例过高、单方随意变更/解除权、无限连带责任、知识产权归属不利、自动续期/默示同意 |
| 🟠 中风险 | 交付期限模糊、付款条件依赖单方审批、不可抗力条款范围过宽、争议解决管辖不利、保密义务期限过长 |
| 🟡 低风险 | 义务措辞不够确定、通知方式不规范、合同生效条件不明确 |

## 🃏 德州扑克基本规则

每位玩家获得 2 张私有底牌，加上 5 张公共牌，组成最强的 5 张牌型。

| 游戏阶段 | 说明 |
|---------|------|
| 翻牌前（Pre-Flop）| 发2张底牌，第一轮下注 |
| 翻牌（Flop）| 翻出3张公共牌，下注 |
| 转牌（Turn）| 翻出第4张公共牌，下注 |
| 河牌（River）| 翻出第5张公共牌，最终下注 |
| 摊牌（Showdown）| 比较牌型，最强者赢得底池 |

### 牌型大全（从强到弱）

| 牌型 | 示例 |
|------|------|
| 🥇 皇家同花顺 | A♠ K♠ Q♠ J♠ 10♠ |
| 同花顺 | 9♥ 8♥ 7♥ 6♥ 5♥ |
| 四条（炸弹）| K♠ K♥ K♦ K♣ 2♠ |
| 葫芦 | A♠ A♥ A♦ K♣ K♠ |
| 同花 | A♣ J♣ 9♣ 5♣ 2♣ |
| 顺子 | 8♠ 7♥ 6♦ 5♣ 4♠ |
| 三条 | J♠ J♥ J♦ 8♣ 3♠ |
| 两对 | A♠ A♥ K♦ K♣ 7♠ |
| 一对 | Q♠ Q♥ 9♦ 6♣ 2♠ |
| 高牌 | A♠ J♥ 8♦ 5♣ 2♠ |
