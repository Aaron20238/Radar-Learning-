# 🃏 德州扑克小程序 — 从新手到高手

一款功能完整的命令行德州扑克游戏，专为新手设计，配备详细的中文教学系统，帮助玩家从零开始快速提升扑克技能。

## 🚀 快速开始

```bash
# 直接运行主程序
python texas_holdem/main.py
```

**Python 版本要求：** Python 3.10+（使用了 `match` 语法和类型注解）

## 🎮 功能特色

### 教学模式
- 每次轮到你行动时，会显示：
  - 当前最佳牌型名称及说明
  - **胜率估算**（蒙特卡洛模拟，实时计算）
  - **听牌提示（Outs）**：还有多少张牌能改善你的手牌
  - **底池赔率分析**：数学上是否值得跟注
  - **起手牌评级**：翻牌前评估你的底牌质量

### 对战模式
- 支持 1-4 位 AI 对手同时对战
- **三种 AI 难度**：
  | 难度 | 说明 |
  |------|------|
  | 新手 AI | 随机出牌，适合完全新手 |
  | 中级 AI | 基于牌力和底池赔率决策 |
  | 高手 AI | 综合胜率、赔率、诈唬，模拟真实高手 |

### 学习中心
内置 8 章教学内容：
1. 基本规则
2. 牌型大全（含示例）
3. 下注操作说明
4. 位置策略
5. 底池赔率
6. 起手牌建议
7. 虚张声势（诈唬技巧）
8. 新手必备10条建议

### 快速测验
5 道精选题目，覆盖核心规则、赔率计算和常见新手误区。

```

```

## 🃏 游戏规则简介

| 阶段 | 说明 |
|------|------|
| 发底牌 | 每人发 2 张私有底牌 |
| 翻牌前 | 第一轮下注 |
| 翻牌 | 翻出 3 张公共牌，下注 |
| 转牌 | 翻出第 4 张公共牌，下注 |
| 河牌 | 翻出第 5 张公共牌，最终下注 |
| 摊牌 | 比较剩余玩家最强 5 张牌型 |

### 牌型从强到弱

| 牌型 | 示例 |
|------|------|
| 皇家同花顺 | A♠ K♠ Q♠ J♠ 10♠ |
| 同花顺 | 9♥ 8♥ 7♥ 6♥ 5♥ |
| 四条 | K♠ K♥ K♦ K♣ 2♠ |
| 葫芦 | A♠ A♥ A♦ K♣ K♠ |
| 同花 | A♣ J♣ 9♣ 5♣ 2♣ |
| 顺子 | 8♠ 7♥ 6♦ 5♣ 4♠ |
| 三条 | J♠ J♥ J♦ 8♣ 3♠ |
| 两对 | A♠ A♥ K♦ K♣ 7♠ |
| 一对 | Q♠ Q♥ 9♦ 6♣ 2♠ |
| 高牌 | A♠ J♥ 8♦ 5♣ 2♠ |

## 📈 进阶学习路线

1. **新手** → 开启教学模式 + 新手 AI 对战，熟悉基本操作
2. **入门** → 学习教学中心内容，完成快速测验
3. **进阶** → 关闭教学模式，挑战中级 AI，尝试自己分析赔率
4. **高手** → 挑战高手 AI，练习诈唬和位置策略
